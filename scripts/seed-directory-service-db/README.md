# Seed DirectoryService

Go-программа заполняет PostgreSQL через `pgx`. SQL встроен в исполняемый файл.
Нужны Go 1.25+ и БД с применёнными миграциями DirectoryService (включая `ltree`).

Из корня репозитория:

```bash
cd scripts/seed-directory-service-db
export DATABASE_URL='postgres://USER:PASSWORD@localhost:5432/DATABASE?sslmode=disable'
go run .
```

Укажите собственные параметры подключения; специальные символы логина/пароля
в URL нужно percent-encode. `sslmode=disable` предназначен для локальной БД.
Файл `.env` автоматически не загружается.

## Схема и данные

| Таблица | Записей | Особенности |
| --- | ---: | --- |
| `departments` | 15 000 | 10 корней, до 5 детей на узел, глубина 0–5 |
| `locations` | 2 500 | Уникальные названия, адреса в пяти городах |
| `positions` | 500 | Должности разных направлений |
| `department_locations` | 30 000 | 1–3 локации на департамент, одна основная |
| `department_positions` | 60 000 | 2–6 должностей на департамент |

`departments.parent_id` ссылается на `departments.id`; `path` — `ltree`
из slug предков и текущего узла через точку. Глубина корня — 0, дочернего
узла — глубина родителя + 1. В БД максимальная длина имени и slug департамента
200 символов; у имён локаций и должностей — 100. Названия локаций имеют
уникальный индекс. Обе таблицы связей имеют UUID-ключи, внешние ключи и
уникальные пары идентификаторов. Удаления по внешним ключам каскадные.

Генерация учитывает эти ограничения. Все записи активны (`deleted_at IS NULL`),
`created_at` и `updated_at` заполняются значениями `now()` из схемы.
Все локации и должности используются в связях. Данные синтетические.

Вставка выполняется одной транзакцией: ошибка откатывает весь запуск.
Повторные запуски используют стабильные UUID и пропускают существующие записи;
параллельные запуски сериализуются advisory lock. Чужие записи не удаляются,
поэтому для непустой БД итоговое количество может быть больше указанного.
Повторный запуск не сбрасывает ручные изменения и soft delete существующих seed-записей.
Ограничение времени выполнения — 5 минут; Ctrl+C отменяет выполнение.
